      Browser Source

      On-stream overlay

      Visible to viewers

      Adds chat messages to the scene output seen by your audience.

      Each OBS scene can use its own Browser Source with ?preset= in the URL.

      1. In OBS Sources, add a Browser source.
      2. Paste the URL above into its URL field.
      3. Set the source width and height for your scene.
      4. Keep CommRelay running while you stream.

      3. Apply the change and place the dock where it is convenient.
