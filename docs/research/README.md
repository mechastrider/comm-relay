# Research в CommRelay

Здесь хранятся переносимые исследования: сверка с кодом и спецификациями, сравнение вариантов, ограничения платформ и выводы, полезные за пределами одной рабочей сессии.

## Актуальные исследования

- [`frontend-refactoring.md`](frontend-refactoring.md) — направление развития admin frontend.
- [`platform-stream-diagnostics.md`](platform-stream-diagnostics.md) — доступные сигналы состояния эфиров Twitch, YouTube и VK Live.

## Архивные снимки

- [`archive/2026-09-03-stream-interface-review.md`](archive/2026-09-03-stream-interface-review.md) — разбор интерфейса и интерактивов, результаты которого распределены по backlog, OpenSpec и canonical specs.

Архивный research-note сохраняет контекст на дату исследования и не обновляется вслед за продуктом. В его начале должна быть ссылка на документ, который хранит актуальный результат.

## Локальные разборы стримов

Полные транскрипты, автоматические разборы, скриншоты и рабочие заметки хранятся вне Git:

```text
var/session_analysis/
└── YYYY-MM-DD-stream-slug/
    ├── analysis.md
    ├── transcript.md
    └── assets/
```

`var/` уже исключён из Git. Не перемещайте оттуда полный материал в репозиторий без явной необходимости: транскрипт может быть шумным, объёмным или содержать данные участников.

Рекомендуемая структура `analysis.md`:

```markdown
# Session: название

Дата:
Источник:
Контекст:

## Наблюдения
## Что уже работает
## Проблемы и трения
## Новые идеи
## Подтверждающие эпизоды
## Кандидаты для backlog
## Что проверить в следующем эфире
```

После разбора переносите в Git только короткие выводы:

- идею или повторяющийся сигнал — в [`../interactive/backlog.md`](../interactive/backlog.md);
- нерешённый выбор — в [`../open-questions.md`](../open-questions.md);
- глубокий переносимый анализ — в отдельный research-note;
- принятое направление — в [`../roadmap.md`](../roadmap.md);
- готовое observable behavior — в OpenSpec change.

Не добавляйте в committed документы ссылку на файл из `var/`: на другом ПК она не откроется. Используйте дату и короткое название сессии либо создайте обезличенный research-note.
