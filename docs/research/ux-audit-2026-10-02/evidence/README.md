## Как читать журнал

- `events`: время, маршрут, группа действий и измеренный результат. Одна запись может включать несколько кликов/вводов; это не исчерпывающий control manifest.
- `network`: наблюдавшиеся API-ответы с методом и статусом; без записи секретов и тел запросов.
- `console`: исходные ошибки и предупреждения, включая намеренный offline и артефакты инструментов. Классификация приведена в отчёте.
- `axe`: результаты 26 проверок axe-core 4.10.3 с селекторами и описаниями нарушений. Повторное нарушение одного компонента не считается новой находкой.
- `inventory`: частичная инвентаризация видимых контролов.

Дополнение: [три повторных замера поиска](performance-search-repeat.json), 15:54 UTC; метод и границы таймера записаны в файле.

## Условия повторения

Собрать frontend (`npm ci`, `npm run build`) и Go-сервер (`go build -o /tmp/comm-relay-ux-server ./cmd/comm-relay-server`). Запустить с отдельным тестовым config/data directory и адресом `127.0.0.1:17889`; не использовать рабочую базу стримера. В этом прогоне конфигурация находилась в `/tmp/comm-relay-ux-data/config.json`, все платформенные коннекторы были выключены. При недоступном системном кэше Go использован `GOCACHE=/tmp/comm-relay-ux-gocache`.

Исходные данные частично создал `comm-relay-seed`: 10 зрителей и история. Seed остановился на UNIQUE constraint при merge achievement unlock; его завершение не заявляется успешным. Для нагрузочной проверки отдельно добавлены 1000 синтетических зрителей с идентификаторами `ux-scale-*`, именами `UX Viewer 0000`…`UX Viewer 0998` и длинным Unicode-именем последнего зрителя; даты распределены за 31 день. Поиск `UX Viewer` давал 999 результатов. Шаги конкретных дефектов приведены в отчёте; сам JSON не является автономным тестом или полным дампом базы.

Chromium: Chrome for Testing 154, production Vite build, localhost без throttling. Основные размеры: 375/768/1024/1280/1440/1920 px; дополнительные 390/520 для OBS CTA. Измерение LCP сделано на свежей загрузке документа, не на hash-навигации. Native OBS/Wails и реальные платформы не участвовали.

Административный насыщенный чат создан инъекцией 25 WebSocket-событий в браузере. Проверка `/overlay/test/chat` использовала настоящий debug API и WebSocket локального сервера. Эти два источника данных различаются намеренно и не являются доказательством live ingest.
