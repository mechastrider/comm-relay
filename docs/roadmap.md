# Roadmap — CommRelay

Этот файл содержит только **согласованный следующий горизонт** и порядок крупных поставок.

- Канон реализованного поведения: [`openspec/specs/`](../openspec/specs/).
- Реестр идей и их статусов: [`interactive/backlog.md`](interactive/backlog.md).
- Видение интерактивной системы: [`interactive/vision.md`](interactive/vision.md).
- Нерешённые продуктовые и UX-вопросы: [`open-questions.md`](open-questions.md).

## Текущая точка

Стримовый MVP и фундамент Interactive System реализованы: локальные зрители и идентичности, session/day/all XP, ограниченная activity-награда, редактируемые команды и contribution awards, message-aware награждение, локальные alert-медиа, управляемая alert-очередь и автоматическая режиссура leaderboard.

Подробности не дублируются здесь. Они находятся в canonical specs, а короткий индекс поставленных инициатив — в разделе `implemented` реестра.

CommRelay остаётся локальным приложением: один процесс, localhost, без облачного relay. Контент конкретного стрима, игры или сообщества остаётся настройкой оператора, а не частью ядра продукта.

## Следующий горизонт

### 1. Достижения и уровни

- Вычислять прогресс из долговечного журнала взаимодействий без полного архива чата.
- Поддержать стандартные редактируемые шаблоны и пользовательские достижения.
- Различать однократные, повторяемые и секретные достижения.
- Добавить уровни по persistent XP и отдельное overlay-событие unlock.

Реестр: [`INT-012`](interactive/backlog.md#int-012).

### 2. Reward Library, Credits и redemptions

- Отделить расходуемые Credits от session/day/all XP.
- Создать библиотеку one-liners, sounds, memes, animations, popups и splash screens поверх уже реализованной локальной медиатеки.
- Хранить явные состояния redemption: accepted, queued, shown, failed и refunded.
- Добавить цену, cooldown, длительность и роли; возвращать Credits при ошибке показа.
- Ограничиться безопасными overlay-actions без произвольного JavaScript и запуска программ.

Реестр: [`INT-013`](interactive/backlog.md#int-013).

### 3. Commands as rewards и Interactive Rules Engine

- Связать существующие команды с элементами Reward Library и Credits, сохранив простой совместимый редактор.
- Обобщить интерактивы в модель `Trigger → Conditions → Actions`.
- Поддержать условия по балансу, роли, cooldown и лимиту сессии.
- Поддержать действия overlay, звука, начисления и списания Credits.

Реестр: [`INT-014`](interactive/backlog.md#int-014).

### 4. Community Awards

- Исследовать доступные реакции и эквивалентные сигналы для каждого connector.
- Настраивать пороги уникальных участников и временные окна.
- Защититься от самонаграждения, повторов и накрутки.
- Создавать автоматический award grant только из надёжно нормализованных сигналов.

Реестр: [`INT-015`](interactive/backlog.md#int-015).

## Кандидаты за горизонтом

Viewer contracts, predictions, voting, роли зрителей, приветствия и внешние события пока не являются обязательствами. Они остаются в [`interactive/backlog.md`](interactive/backlog.md) до исследования или отдельного продуктового решения.

Внешнее сравнение со StreamElements, Streamlabs, Twitch Channel Points и Mix It Up проводится для поиска конкретных пробелов, а не для автоматического копирования их feature set.

## Сознательные границы

- Нет облачной глобальной базы, аккаунтов CommRelay и синхронизации между ПК.
- `config.json` не переносится в SQLite.
- Полный лог всех сообщений не хранится автоматически.
- Ядро не привязывается к одной игре или неудаляемому набору команд.
- Идентичности не склеиваются автоматически по похожему нику.
- Session XP и persistent XP не расходуются; покупки используют отдельные Credits.
- Rules Engine первого горизонта не выполняет произвольный JavaScript, программы и прямое управление игрой.
- Одинаковые community reactions не обещаются платформам, connector которых не отдаёт надёжный сигнал.
