# Continue

Continue work on CommRelay from the backlog.

## Instructions

1. Read `AGENTS.md`, `docs/concept.md`, and `docs/task-tracker.md`.
2. Find the first row in `docs/task-tracker.md` whose status is `todo`.
3. Open the linked task file under `docs/tasks/`.
4. Before making code changes, update the task status to `in_progress` in both:
   - `docs/task-tracker.md`
   - the linked task file
5. Work on exactly one task.
6. Follow all relevant project skills from `.agents/skills/`.
7. Keep changes scoped to the task file.
8. Before finishing, run the checks listed in the task file and the checks required by `.cursor/rules/`.
9. If the task is complete, update status to `done` in both files and add a short completion note to the task file.
10. If the task is blocked, update status to `blocked` in both files and write the blocker clearly in the task file.
11. In the final response, include:
    - task ID and title
    - changed files
    - checks run
    - any blockers or follow-up tasks

If there are no `todo` tasks left, report that the backlog is empty.
