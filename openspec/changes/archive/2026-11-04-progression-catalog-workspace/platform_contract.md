# Platform Contract

## Supported Matrix

Existing browser and Wails supported platforms remain unchanged. All changes are in the shared React admin.

## OS Integration

Not applicable: filesystem/native dialogs, clipboard/OS notifications, tray/menu/global shortcuts, protocol/file associations, single instance/deep open, child processes/IPC, and sleep/wake/shutdown are untouched. Alert settings use an HTML dialog, not a native OS dialog.

## Security / Privacy / Trust Boundary

Existing localhost API, credentials and escaping contracts remain unchanged.

## Not applicable areas

No OS-specific implementation or new permissions are introduced.
