## Why

The user wants the CommRelay wordmark to follow Mech-Comm's two-part white/orange typography. The current header is a single amber word with a glow.

## What Changes

- Display Comm-Relay in the admin header, About identity, and error heading.
- Use an off-white first part and hyphen, orange Relay, bold monospace uppercase typography, and no glow.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `admin-design-system`: consistent product wordmark.

## Impact

Admin presentation and changelog only. Existing icons, technical names, executable names, API, and configuration remain unchanged.
