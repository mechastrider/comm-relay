## Connections

Add a GoodGame tab in Settings → Platforms with an enable checkbox and labeled channel field. Accept a key or a full channel link. An invalid enabled channel returns a localized field error, selects the affected tab and focuses the field. Save and reset use the existing section-wide draft.

Show the connection state in the header when enabled, and expose detailed state and message count in Diagnostics. Live, OBS dock and overlay use unified messages.
