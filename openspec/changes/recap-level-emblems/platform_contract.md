# Platform Contract
## Supported Matrix
Existing supported browser, desktop and OBS platforms share the same SVG rendering.
## OS Integration
Unchanged.
## Security / Privacy / Trust Boundary
Built-in SVG paths only; no new permissions or private identity data.
## Not applicable areas
Filesystem/dialogs, clipboard/notifications, tray/menu/shortcuts, associations, single instance, child processes/IPC and sleep/wake/shutdown are unchanged. PNG uses the existing export path.
